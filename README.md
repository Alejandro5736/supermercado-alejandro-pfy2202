# Supermercado App - Evaluación Formativa 2 (Frontend II)

Aplicación web desarrollada en **React** y estilizada con **Tailwind CSS** para la gestión de inventario de un supermercado, implementando estado global (`useState`) y enrutamiento con `react-router-dom`.

## 🚀 Tecnologías Utilizadas
* **React** (Create React App)
* **React Router DOM** (Navegación por rutas)
* **Tailwind CSS v3** (Estilos y diseño responsivo)

## 📌 Funcionalidades del Proyecto
* **Gestión de Inventario:** Visualización dinámica de artículos en una tabla detallada (ID, nombre, marca, tipo, stock y precio).
* **Formulario de Registro:** Permite ingresar nuevos productos al estado global especificando obligatoriamente nombre, marca y tipo.
* **Navegación:** Menú interactivo con vistas de Inicio (Inventario), Ingresar Artículo, Quiénes Somos y Contáctanos.
